Bank Management System

A simple Bank Management System developed using Python and Tkinter. This application allows users to perform basic banking operations such as depositing money, withdrawing money, and viewing the current account balance through a graphical user interface.

Features
Deposit money
Withdraw money
Real-time balance updates
Input validation
Insufficient balance protection
User-friendly GUI
Technologies Used
Python
Tkinter
How to Run
Clone the repository.
Open the project folder.
Run the following command:
python bank_app.py
